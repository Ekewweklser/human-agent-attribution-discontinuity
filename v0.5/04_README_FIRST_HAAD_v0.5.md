# HAAD Version 0.5 Public Release

**Author:** Kevin V. Watson  
**Release date:** August 25, 2026  
**Version 0.5 DOI:** [10.5281/zenodo.22099968](https://doi.org/10.5281/zenodo.22099968)  
**Prior deposited version:** [Version 0.4, DOI 10.5281/zenodo.21683276](https://doi.org/10.5281/zenodo.21683276)  
**Status:** Public release  
**Version relationship:** Version 0.5 is the new version associated with DOI 10.5281/zenodo.22099968. Version 0.4 remains preserved at DOI 10.5281/zenodo.21683276.  

Human-Agent Attribution Discontinuity (HAAD) is a forensic and assurance methodology for determining how far available evidence supports attribution of a consequential AI-agent action to a natural person.

This release is not a validated standard, forensic doctrine, or legal attribution framework. It preserves the Version 0.4 canonical fourteen-dimension register and adds an MCP-mediated attribution application profile, operational workpapers, and structured scenarios addressing later constraints, subject-system representations, component implementation integrity, approval and effective-target comparison, decision-basis state, cross-run dependence, layered organizational attribution, outcome stages, quantitative activity-share claims, human decision gates, and campaign aggregation.

## Controlled material excluded

The sealed *HAAD Structured-Scenario Pilot Reference Model and Agreement Instrument* is maintained separately under controlled access and is intentionally excluded from the public release package. Public disclosure before practitioner and independent-review analyses are complete would compromise the testing design. The public packs and controlled companion are design exemplars, not completed pilot outputs. Anyone exposed to a pack or its reference model is ineligible to treat that pack as an unseen Round 2 scenario. Actual testing requires newly frozen transformed or composite scenarios, a construction oracle, recognizability review, access records, and post-test exposure reporting.
