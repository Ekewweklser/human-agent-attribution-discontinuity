## Release controls

- Version 0.4 remains the deposited record and is not modified by this release.
- Version 0.5 must be created as a new version of the existing Version 0.4 Zenodo record so that both records remain linked in the same version chain.
- Version 0.5 preserves the canonical fourteen-dimension register.
- MCP remains an application profile, not a fifteenth attribution dimension.
- The added approval, effective-target, decision-state, outcome-stage, cross-run, organizational, and campaign controls are application rules and workpapers, not additional attribution dimensions.
- Public pilot packs are design exemplars, not empirical outputs or eligible unseen instruments for practitioners previously exposed to them.
- The testing programme remains planned. No independent-practitioner result is reported for any HAAD version.
- Create the final PDFs only after the Markdown and Word sources are frozen. Reverify hashes, references, filenames, metadata, internal links, and layouts before publication.
