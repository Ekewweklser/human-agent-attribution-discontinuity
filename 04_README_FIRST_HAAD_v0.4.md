# HAAD Version 0.4 Public Release

**Author:** Kevin V. Watson  
**Release date:** July 29, 2026  
**DOI:** [10.5281/zenodo.21683276](https://doi.org/10.5281/zenodo.21683276)  
**Status:** Public-review and structured-testing draft  

Human-Agent Attribution Discontinuity (HAAD) is a forensic and assurance methodology for determining how far available evidence supports attribution of a consequential AI-agent action to a natural person.

This release is not a validated standard, forensic doctrine, or legal attribution framework. As of the release date, no independent-practitioner Round 1 or Round 2 result is reported. Version 0.4 revisions are based on review and structured scenario analysis.

## Reading order

Zenodo displays files alphabetically. Numeric prefixes enforce this reading order:

3. `02_HAAD_Practitioner_Workpapers_v0.4` - operational forms.

Markdown, editable Word, and archival PDF versions are supplied. Files with the same numeric prefix contain the same substantive document in different formats.

## Controlled material excluded

The sealed *HAAD Structured-Scenario Pilot Reference Model and Agreement Instrument* is intentionally excluded from this public release. Public disclosure before practitioner and independent-review analyses are complete would compromise the testing design.
